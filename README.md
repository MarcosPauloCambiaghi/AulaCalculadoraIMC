# 🧮 Aula Calculadora IMC

Um aplicativo Android simples para calcular o **Índice de Massa Corporal (IMC)**.  
Desenvolvido com **Kotlin/Java** no **Android Studio**, como parte dos estudos de desenvolvimento mobile.

---

## 📱 Funcionalidades

- Inserir peso e altura  
- Calcular IMC automaticamente  
- Exibir o resultado com classificação (abaixo do peso, ideal, sobrepeso etc.)  
- Interface simples e intuitiva  

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Kotlin  
- **IDE:** Android Studio  
- **SDK:** Android SDK  
- **Layout:** XML (Material Design Components)
